- FIX schema hash depended on the device locale because `sortObject()` used `localeCompare()` without a locale. In Czech and Slovak "ch" sorts after "h", so a schema with keys like `chunk_id` and `hint` got a different hash after the device or app language changed, and `addCollections()` threw `DB6` for an unchanged schema. Keys are now sorted with a fixed `en` collation, and a stored schema that only differs in key order gets its hash updated instead of throwing `DB6`.
