- Added a testcase in `test/unit/rx-storage-dexie.test.ts` that reproduces the dexie RxStorage connection leak: after `close()` the underlying Dexie connections stay open and the state cache keeps the entry, so creating a database with the same name again after the IndexedDB databases were deleted throws `DatabaseClosedError`. The test fails on master and passes with the fix from [#8797](https://github.com/pubkey/rxdb/pull/8797). [#8793](https://github.com/pubkey/rxdb/issues/8793)
