- ADD `getConnectionHandlerNostr()` to the WebRTC replication plugin. Peers find each other over [Nostr](https://nostr.how/en/what-is-nostr) relays instead of a signaling server. Signals are sent as signed, NIP-44 encrypted ephemeral events, and `getNostrPublicKeyOfPeer()` returns the verified public key of a peer for use in `isPeerValid()`. Added tests for the Nostr signaling with multiple relays, peer validation and unreachable relays.
