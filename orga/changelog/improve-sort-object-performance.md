- IMPROVE performance of `sortObject()` (used for schema normalization and query cache keys) by returning primitives early, replacing `forEach()`/`map()` with plain `for` loops and sorting keys by UTF-16 code units instead of `localeCompare()`. The first `localeCompare()` call initializes the ICU collator, which took about 6ms in Chrome and was about 15% of the initial database load when creating 5 collections with the Dexie storage. [#9153](https://github.com/pubkey/rxdb/pull/9153)
- CHANGE `sortObject()` sorts object keys and string array items by UTF-16 code units so the result no longer depends on the locale of the JavaScript runtime. This changes the schema hash of most schemas.
