- Added the [dbviewer plugin](https://rxdb.info/dbviewer.html) (beta): a database viewer devtool that mounts into any DOM element and lets you inspect and edit a running RxDatabase or a static `exportJSON()` dump. It ships a data grid with a Mango query bar and document drawer, a JSON view, a live activity map, and schema, query-analysis, replication, changes and storage panels. The hosted viewer page can also pair with a database on another device over WebRTC via `connectRxDBViewer()`. Added testcases for the viewer helpers and the dump data source.
