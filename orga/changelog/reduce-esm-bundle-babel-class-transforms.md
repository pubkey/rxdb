- IMPROVE Reduce the ESM bundle size by no longer down-transpiling native class syntax in the `dist/esm` build. The class/syntax-lowering babel transforms now only run for the CJS/es5 build, which removes the `@babel/runtime` helper imports (`inheritsLoose`, `createClass`, ...) from the ESM output. This shrinks the measured core+memory bundle by about 1.35 KB gzip (~3%) and removes `@babel/runtime` from the ESM tree entirely.
