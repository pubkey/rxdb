- FIX `addRxPlugin()` now treats re-registration of a plugin with the same name (but a different object reference) as a no-op instead of throwing `PL3`. This fixes a crash caused by ESM/CJS module duplication in bundlers such as webpack (CRA), where `replicateCouchDB` internally imports `RxDBLeaderElectionPlugin` via a CJS relative path while the app imports it via the ESM entry point, resulting in two distinct object references for the same plugin.
