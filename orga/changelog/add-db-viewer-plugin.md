- Added the `db-viewer` plugin, a database viewer and editor for a running [RxDatabase](https://rxdb.info/rx-database.html). It renders a data grid and JSON view with a Mango query bar, a document drawer that previews the exact upsert before it runs, and panels for the live activity map, schema analysis, query explain, replication, changes and storage. Mount it with `mountRxDBDbViewer(database)` or `database.mountDbViewer()`. The [angular example](https://github.com/pubkey/rxdb/tree/master/examples/angular) opens it from a button. Added testcases for the metrics window, the selector parsing, the document diff and the grid column selection.
