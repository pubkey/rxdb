- FIX replication: when the first `start()` of a replication rejected, the error was an unhandled rejection that was not emitted on `error$`, and every later `start()`, `pause()` and `remove()` rejected with the same error because the `startQueue` stayed rejected, so the replication could not be started again without a page reload. A failed start is now emitted on `error$` as `RC_START` and a later `start()` retries it. The internal `start()` calls of `autoStart` and `toggleOnDocumentVisible` no longer create unhandled rejections. Added a test case for it in `test/unit/bug-report.test.ts`. Fixes [#9127](https://github.com/pubkey/rxdb/issues/9127).
