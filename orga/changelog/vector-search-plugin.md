- Added the vector search to the [vector plugin](https://rxdb.info/vector.html). Next to the already existing comparison functions, the plugin now provides `extendSchemaWithVectorIndex()` and `RxCollection.addVectorIndex()` to store embeddings in indexed fields and to run approximate nearest neighbor searches with `search()`, `searchByRange()` and `searchFullScan()`. The index values are calculated deterministically so that they stay correct across [replication](https://rxdb.info/replication.html). Added testcases for the new functions.
