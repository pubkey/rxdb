- ADD the `vector-turboquant` plugin that adds [vector search](https://rxdb.info/vector-search.html) to RxDB. It implements the [TurboQuant](https://arxiv.org/abs/2504.19874) quantizer, so an embedding is stored with 1, 2 or 4 bits per dimension instead of 32 bits as `float32`. `collection.addVectorIndex()` fills the index from the documents of an [RxCollection](https://rxdb.info/rx-collection.html) and keeps it in sync with the change stream, `search()` returns the nearest neighbors with `cosine`, `dotProduct` or `euclidean` scoring and supports an allowlist to combine a vector search with a normal query. Added testcases for the codebook, the rotation, the index, the serialization and the collection integration.
