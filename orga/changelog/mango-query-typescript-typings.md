- Added end-to-end TypeScript typings for [mango queries](https://rxdb.info/rx-query.html): selector keys and sort fields are checked against the document type including nested dot-paths, and query operators are constrained by the type of the field they run on, for example `$regex` on a number field is now a compile error. Dot-paths are generated for up to 6 levels of nesting. Dynamically built queries can opt out by casting to `MangoQuery<any>`. Added type tests for valid and invalid queries.
- The minimum supported TypeScript version is now 4.1 because the query typings use template literal types.
