- FIX: Changed `validate-ajv` plugin to use named import `import { Ajv } from 'ajv'` instead of default import to fix `TypeError: a is not a constructor` in webpack 5 bundles. The webpack 5 scope-hoisting creates an arrow-function getter for CJS default imports, and arrow functions cannot be used with `new`. The named import avoids this by accessing the `Ajv` property directly on the module exports.
