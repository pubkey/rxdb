ADD `replicationState.conflict$` which emits each push conflict that was reported by the remote together with the output of the `conflictHandler`. Also `awaitDocumentPushed()` now resolves when the push of the document was answered with a conflict, so callers can watch `conflict$` for the documents primary key until `awaitDocumentPushed()` resolves to distinguish an accepted push from a rejected one.
