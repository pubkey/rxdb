Motion study for the RxDB brand mark

RxDB Logo Motion

Sixteen animated versions of the RxDB logo. Each one is built from the five shapes of the original mark (frame, three layers, two corner pieces) and ties the motion to something the database does.

Logo + context from rxdb.info

The Local-First Database for JavaScript Apps

RxDB is a NoSQL database for JavaScript that runs directly in your app. With a local-first design, it delivers zero-latency queries even offline, and syncs with any backend.

  • Build apps that work offline
  • Sync with any backend
  • Observable realtime queries
  • All JavaScript runtimes supported

The three layers break out of the frame and become the feature list, the foot piece carries the runtimes, then the logo winks. Copy from rxdb.info.

Signature moment

The Wink

Two takes on the wink. The character version adds eyes to the top layer and a smile to the middle layer, and the pupils follow your pointer. The minimal version uses only the original shapes: the top layer closes like an eyelid and the corner piece lifts like an eyebrow.

Character wink

0.7s · on click + every 3rd blink

The right eye closes into an arc, the corner piece lifts, the smile turns into a smirk and a spark pops out. Blinks run on a random 2.5 to 5 second interval. Leave the pointer still for 8 seconds and it falls asleep. Move or tap to wake it.

minimal wink

Minimal wink

3.2s · loop · ease-out

No added features. The top layer squeezes to 8% height, overshoots to 110% on the way back, and the middle layer squashes as follow-through.

Interactive

Document Swarm

The mark rebuilt from squares, where each square stands for one document. Move your pointer through it to push documents away. Click the artboard or press Scatter to throw them all, then watch every document find its place again.

Versions

Motion That Explains the Database

Each loop maps to a feature listed on rxdb.info. All motion is CSS keyframes or the Web Animations API, with no libraries and no raster assets.

intro

Build-in

2.2s · once · ease-pop

The frame draws itself, then the three layers slide in like documents written to storage. Made for a page-load intro.

query.$.subscribe()

Reactive stream

2.4s · loop · ease-out

Each layer emits in turn with a ripple, like results from an observable query. Subscribe once and every change arrives.

replication

Replication

3s · loop · linear

Documents travel between a client and a server. Pushes go right, pulls come back, and the receiving layer lights up on arrival.

online · synced offline · writing locally
offline-first

Offline-first

6s · loop · ease-out

The connection drops, the logo keeps writing locally and queues three changes. When the connection returns, the queue flushes upstream.

swap storage

Storage swap

2.2s · loop · WAAPI

The bottom layer slides out and a different storage slides in. Switching storages is a configuration change, not a rewrite.

awaitInitialReplication() loader

Loader

1.8s · loop · ease-out

The layers fill and drain in sequence while the corner piece turns. For the moment an app waits on the first sync.

storage layers

Isometric stack

6s · loop · CSS 3D

The mark tilts into an isometric view and the three layers lift off the frame like a stack of storage layers, then settle back.

conflict handler

Conflict handling

4s · loop · ease-out

Two offline edits of the same document collide on the middle layer, shake, and resolve into one revision.

encryption

Encryption

5s · loop · JS scramble

The corner piece locks, the layers go dark and fill with ciphertext, then decrypt back to the brand colors.

Key compression

Leader election

2.4s · loop · WAAPI

Three tabs share one database. When the leader tab closes, the crown moves to the next tab, so only one tab talks to the server.
